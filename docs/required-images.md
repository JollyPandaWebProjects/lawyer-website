# تصاویر موردنیاز (required-images)

در نسخه فعلی، به‌جای تصاویر واقعی از ایموجی (Emoji) در `src/data/media.json` استفاده شده است تا سایت بدون تصویر واقعی نیز کامل و بدون خطا نمایش داده شود. پیش از انتشار نهایی، تصاویر زیر باید تهیه و جایگزین شوند.

| کلید در media.json | مسیر پیشنهادی | ابعاد پیشنهادی | فرمت | توضیح |
|---|---|---|---|---|
| `heroPortrait` | `/public/images/hero-portrait.webp` | ۸۰۰×۸۰۰ (مربع) | WebP | تصویر پرتره حرفه‌ای برای بخش Hero |
| `aboutImage` | `/public/images/about.webp` | ۹۰۰×۱۱۰۰ | WebP | تصویر دفتر یا محیط کاری برای بخش About |
| `openGraph.image` / `twitter.image` (در seo.json) | `/public/images/og-cover.webp` | ۱۲۰۰×۶۳۰ | WebP | تصویر پیش‌نمایش هنگام اشتراک‌گذاری لینک |
| `favicon` | `/public/favicon/favicon.png` | ۵۱۲×۵۱۲ | PNG | یک فایل Placeholder ساده در حال حاضر موجود است |

## راهنمای جایگزینی

1. فایل تصویر را در مسیر `public/images/` قرار دهید.
2. در `src/data/media.json`، مقدار مربوطه را به شکل زیر تغییر دهید:

```json
{
  "type": "image",
  "value": "/images/hero-portrait.webp",
  "alt": "متن جایگزین توصیفی"
}
```

هیچ تغییری در کد کامپوننت‌ها لازم نیست — `MediaRenderer` نوع محتوا را به‌صورت خودکار تشخیص می‌دهد.

## نکات فنی

- تمام تصاویر باید با فرمت WebP و فشرده‌سازی مناسب (حداکثر ~150KB برای تصاویر بزرگ) بارگذاری شوند.
- متن `alt` باید توصیفی، فارسی و معنادار باشد (نه صرفاً نام فایل).
- از انتشار تصاویر با کیفیت پایین یا واترمارک استفاده نشود.
